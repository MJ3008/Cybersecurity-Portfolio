# File Organizer (Python)

This is a Python script that automatically organizes files in a folder into different categories.

## Features
- Organizes files into folders like Images, Documents, Videos
- Automatically creates folders if they do not exist
- Easy to use

## Technologies Used
- Python
- os module
- shutil module

## How to Run

1. Open terminal
2. Run the script:

python file_organizer.py

3. Enter the folder path to organize
